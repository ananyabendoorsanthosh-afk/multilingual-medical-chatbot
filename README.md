# Multilingual Medical Chatbot

## Project Description

This project develops a multilingual chatbot that can understand
questions in multiple languages and maintain conversational context
when the user switches languages.

## Supported Languages

- English
- Hindi
- Kannada
- Spanish

## Features

- Automatic language detection
- Multilingual responses
- Intent detection
- Conversation context retention
- Language switching
- Cross-lingual interaction
- Ambiguity handling

## Files

### chatbot.py

Contains the main multilingual chatbot implementation.

### test_cases.txt

Contains test inputs, expected languages, intents, and expected results.

### README.md

Contains project documentation and instructions.

## Testing

The chatbot was tested using English, Hindi, Kannada, and Spanish
questions. Tests verify language detection, intent recognition,
language switching, and conversation continuity.

## How to Run

Run the following command:

python chatbot.py

## Expected Outcome

The chatbot should identify the user's language, understand the
user's intent, maintain conversation context, and respond in the
appropriate language.

## Disclaimer

This is an educational project and should not be used as a substitute
for professional medical advice.
